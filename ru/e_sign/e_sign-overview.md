# E-Contract — Электронное подписание договоров

E-Contract — это сервис CNS Platform для трансграничного электронного подписания договоров между казахстанскими и китайскими компаниями. Он позволяет системам документооборота, торговым платформам и любым бизнес-приложениям встраивать юридически значимое подписание напрямую в свои продукты — без необходимости самостоятельно выстраивать отношения с удостоверяющими центрами.

---

## Для кого этот сервис

E-Contract ориентирован на сторонних интеграторов — компании, которые создают продукты в области документооборота, внешнеторговых операций или финансовых услуг. Если ваша платформа сопровождает трансграничные сделки между Казахстаном и Китаем и вам нужно, чтобы договоры подписывались электронно и имели юридическую силу в обеих странах, E-Contract решает именно эту задачу.

Интегратор подключается к CNS OpenAPI, отправляет договор через один запрос и получает готовую ссылку на страницу подписания. Весь процесс взаимодействия с китайским удостоверяющим центром (УЦ) скрыт внутри платформы.

---

## Как устроен сервис

CNS Platform интегрирована с аккредитованным китайским удостоверяющим центром. После подключения вам не нужно выстраивать отношения с УЦ самостоятельно или разбираться в его API — CNS берёт на себя всё взаимодействие: маршрутизацию, аутентификацию, отслеживание статуса и фиксацию результата.

---

## Что сервис берёт на себя

После отправки договора через API платформа самостоятельно:

- передаёт договор в китайский УЦ через защищённый прокси;
- уведомляет подписанта по SMS и email;
- отслеживает статус подписания асинхронно, не нагружая ваш бэкенд;
- сохраняет подписанный документ и доказательную базу — файл, хеш, метку времени TSA, идентификатор блокчейн-транзакции;
- создаёт биллинговое событие по вашему аккаунту CNS при успешном подписании.

Вы получаете уведомление о завершении через вызов вашего `sign-complete` эндпоинта.

---

## Соответствие требованиям

Подписание физически выполняется на инфраструктуре, размещённой в Китае. Это требование Статьи 71, пункта 3 Закона КНР о кибербезопасности: операторы критической информационной инфраструктуры не вправе хранить персональные данные и значимые данные за пределами Китая.

Со стороны CNS на платформе хранятся только статус договора, метаданные и зашифрованная ссылка на подписанный файл. Персональные данные участников сделки через серверы CNS не проходят и не сохраняются.

Передача данных между CNS и китайским УЦ маршрутизируется через защищённый прокси Alibaba Cloud Singapore. Измеренная задержка составляет 60-156 мс — приемлемо для асинхронного процесса подписания.

## С чего начать

Для подключения к E-Contract вам потребуется:

1. Активный биллинговый аккаунт CNS.
2. API-ключ, выданный во вкладке **API Keys** консоли CNS.
3. Ознакомьтесь с разделом [Как это работает](./e_sign-concepts.md), чтобы понять жизненный цикл договора и ключевые концепции.
4. Перейдите к [API-справочнику](./e_sign-api.md) для начала интеграции.

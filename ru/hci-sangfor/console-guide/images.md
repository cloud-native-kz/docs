# Образы и шаблоны

Образы — основа для создания виртуальных машин. Платформа предоставляет **Публичные образы ВМ** (предварительно настроенные образы ОС, поддерживаемые платформой) и **Частные образы ВМ** (образы, загруженные или созданные вами).

---

## Публичные образы ВМ

Публичные образы предоставляются и поддерживаются администратором платформы. Они включают предустановленные операционные системы (Windows Server, CentOS, Ubuntu и другие).

Для использования публичного образа выберите его в поле **Образ** при создании ВМ (**Вычисления** → **Виртуальные машины** → **Создать** → шаг 2).

---

## Частные образы ВМ

Частные образы хранятся в **Репозитории частных образов** вашего тенанта. Вы можете создать частные образы, загрузив ISO-файл или преобразовав существующую ВМ в готовый встроенный образ.

Перейдите в **Вычисления** → **Образы** → **Частные образы ВМ** для управления частными образами.

---

## Загрузка ISO

Загрузите ISO-образ ОС для установки с нуля при создании ВМ.

1. Перейдите в **Вычисления** → **Образы** → **Частные образы ВМ**.
2. Нажмите **Загрузить**.
3. Выберите локальный ISO-файл, укажите тип **Операционной системы** и выберите **Пул ресурсов**.
4. Нажмите **Загрузить** для начала загрузки.
5. После завершения нажмите **Готово** для закрытия или **Закрыть** для загрузки дополнительных файлов.

---

## Создание встроенного образа из ВМ

Встроенный образ фиксирует полное состояние настроенной ВМ, чтобы быстро развёртывать идентичные копии.

**Предварительные условия:**
- В ВМ должны быть установлены VM Tools.
- Рекомендуется включить горячее добавление ЦПУ и памяти в **Расширенных** настройках ВМ перед созданием образа.

**Шаги:**

1. Перейдите в **Вычисления** → **Виртуальные машины**, выберите ВМ.
2. Нажмите **Ещё** → **Изменить**. На вкладке **Расширенные** включите горячее добавление ЦПУ и памяти, затем нажмите **ОК**.
3. Нажмите **Ещё** → **Создать образ**.
4. Введите **Имя** и **Описание** образа.
5. Выберите тип **Операционной системы** и **Пул ресурсов**.
6. Нажмите **ОК** для начала создания образа.

Образ появится в **Частных образах ВМ** после завершения создания.

---

## Использование частного образа для создания ВМ

1. Перейдите в **Вычисления** → **Виртуальные машины** → **Создать**.
2. В шаге выбора образа переключитесь на **Частные образы ВМ** и выберите нужный образ.
3. Продолжите работу с мастером создания ВМ.

---

## Экспорт ВМ

Вы можете экспортировать ВМ в формате OVA, VMA, OVF, MF или VMDK для использования на других платформах или в качестве офлайн-архива.

Шаги описаны в разделе [Экспорт ВМ](virtual-machines.md#экспорт-вм).

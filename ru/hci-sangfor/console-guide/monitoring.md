# Мониторинг и оповещения

Платформа предоставляет панель мониторинга для отслеживания производительности ВМ и сети, центр оповещений для просмотра событий платформы и обзор квот ресурсов.

---

## Панель мониторинга

Панель мониторинга отображает графики производительности в реальном времени и за прошлые периоды для ваших ВМ и эластичных IP.

### Создание панели мониторинга

1. Перейдите в **Центр мониторинга** → **Панель мониторинга**.
2. Нажмите **Новая панель**.
3. Выберите **Тип объекта**:
   - **Виртуальная машина** — мониторинг ЦПУ, памяти, диска, пропускной способности сети, IOPS и скорости ввода-вывода
   - **Эластичный IP** — мониторинг входящего/исходящего трафика
   - **Общая пропускная способность** — мониторинг использования общей полосы
4. Выберите конкретный ресурс или ресурсы из списка.
5. Отметьте метрики для отображения.
6. Нажмите **ОК**.

Панель появится на дашборде и будет обновляться в реальном времени.

### Метрики производительности ВМ

При мониторинге виртуальной машины доступны следующие метрики:

| Метрика | Описание |
|---|---|
| **Использование ЦПУ** | Утилизация vCPU (%) |
| **Использование памяти** | Используемая RAM по отношению к общей |
| **IOPS** | Операции чтения/записи диска в секунду |
| **Скорость ввода-вывода** | Скорость чтения/записи диска |
| **Пропускная способность** | Входящая/исходящая пропускная способность сети |
| **Пропускная способность (pps)** | Пакетов в секунду |
| **Использование диска** | Используемое дисковое пространство |

### Графики производительности ВМ

Для просмотра подробных данных о производительности отдельной ВМ:

1. Перейдите в **Вычисления** → **Виртуальные машины**, нажмите на имя ВМ.
2. Вкладка **Сводка** отображает индикаторы ЦПУ и памяти, а также временные графики.
3. Используйте селектор диапазона времени (Последний час, произвольный диапазон) для настройки вида.
4. Нажмите **Экспортировать** на графике для скачивания в формате PNG, JPEG, SVG или CSV.

## Оповещения

Раздел оповещений отображает все события платформы, затрагивающие ваши ресурсы.

1. Перейдите в **Центр мониторинга** → **Оповещения**.
2. Список оповещений содержит:

| Столбец | Описание |
|---|---|
| **Серьёзность** | Критическое, Предупреждение или Информация |
| **Время** | Когда было создано оповещение |
| **Тип объекта** | Тип затронутого ресурса |
| **Объект** | Имя конкретного ресурса |
| **Пул ресурсов** | Кластер, где находится ресурс |
| **Событие** | Описание типа оповещения |

Используйте фильтры для сужения оповещений по диапазону времени, серьёзности или типу объекта.

> Оповещения на уровне ВМ (например, предупреждения об истечении срока, сбои резервного копирования) также отображаются на вкладке **Оповещения** на странице сводки каждой ВМ.

## Квота ресурсов

Отслеживайте текущее использование ресурсов по отношению к квоте, выделенной администратором платформы.

1. Нажмите на имя учётной записи в правом верхнем углу → **Изменить квоту ресурсов**.
2. **Обзор квоты** показывает все категории ресурсов:

**Вычисления:**

| Ресурс | Описание |
|---|---|
| **Виртуальные машины** | Разрешённое количество ВМ по отношению к используемым |
| **ЦПУ** | Всего выделенных ядер vCPU |
| **Память** | Всего выделенной RAM |

**Хранилище:**

| Ресурс | Описание |
|---|---|
| **Высокопроизводительное хранилище** | Квота SSD-хранилища |
| **Среднепроизводительное хранилище** | Квота HDD-хранилища |
| **Репозиторий резервных копий** | Квота хранилища для резервных копий ВМ |
| **Репозиторий частных образов** | Квота хранилища для частных образов |

**Сеть:**

| Ресурс | Описание |
|---|---|
| **Эластичные IP** | Количество выделенных публичных IP |
| **Пропускная способность** | Квота пропускной способности по линиям |

**NFV-устройства:**

| Ресурс | Описание |
|---|---|
| **vAD** | Экземпляры контроллера доставки приложений |
| **vNGAF** | Экземпляры виртуального межсетевого экрана нового поколения |
| **SSL VPN** | Экземпляры SSL VPN |

Если вам нужно больше ресурсов, отправьте запрос через **Заявки**.

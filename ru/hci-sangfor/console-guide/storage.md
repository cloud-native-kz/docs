# Хранилище

Управление хранилищем на платформе осуществляется через конфигурацию дисков ВМ и квоты ресурсов. Каждая ВМ имеет системный диск и может иметь дополнительные диски данных.

---

## Конфигурация дисков ВМ

Размеры и типы дисков настраиваются при создании или изменении ВМ.

### Настройка дисков при создании ВМ

При создании ВМ (**Вычисления** → **Виртуальные машины** → **Создать**) настройте хранилище в разделе **Хранилище**:

| Поле | Описание |
|---|---|
| **Тег хранилища** | Уровень хранилища — например, **Высокопроизводительное хранилище** (на SSD) или **Среднепроизводительное хранилище** |
| **Размер диска** | Ёмкость системного диска в ГБ |
| **Дополнительные диски** | Добавьте дополнительные диски данных с указанием размера и тега хранилища |

### Добавление диска к существующей ВМ

1. В списке ВМ нажмите **Ещё** → **Изменить**.
2. Добавьте новый диск в разделе хранилища.
3. Нажмите **ОК**.

Новый диск появится в гостевой ОС как неинициализированное блочное устройство. Перед использованием его нужно отформатировать и смонтировать.

**Linux:**

```bash
# Определить новый диск
lsblk

# Разметить, отформатировать и смонтировать (пример: /dev/vdb)
sudo fdisk /dev/vdb
sudo mkfs.ext4 /dev/vdb1
sudo mkdir /data && sudo mount /dev/vdb1 /data
echo '/dev/vdb1 /data ext4 defaults 0 2' | sudo tee -a /etc/fstab
```

**Windows:**

1. Откройте **Управление дисками** (`diskmgmt.msc`).
2. Щёлкните правой кнопкой по новому диску → **Инициализировать диск**.
3. Создайте новый простой том и назначьте букву диска.

## Квота хранилища

Администратор платформы выделяет квоту хранилища для вашего тенанта. Для просмотра текущего использования и лимитов:

1. Нажмите на имя учётной записи в правом верхнем углу → **Изменить квоту ресурсов**.
2. В разделе **Обзор квоты** отображается:

| Ресурс | Описание |
|---|---|
| **Высокопроизводительное хранилище** | Квота SSD-хранилища и текущее использование |
| **Среднепроизводительное хранилище** | Квота HDD-хранилища и текущее использование |
| **Сетевое хранилище** | Квота сетевого хранилища |
| **Репозиторий резервных копий** | Квота для резервных копий ВМ |
| **Репозиторий частных образов** | Квота для частных образов ВМ |

Если вам нужно больше квоты хранилища, отправьте запрос через **Заявки**.

---

## Хранилище резервных копий

Резервные копии ВМ расходуют квоту **Репозитория резервных копий**. Для проверки использования перейдите в **Изменить квоту ресурсов** (см. выше) или просмотрите статус резервных копий на странице сводки ВМ (вкладка **Резервные копии и DR**).

Для настройки резервного копирования по расписанию см. [Виртуальные машины — Политика резервного копирования по расписанию](virtual-machines.md#резервное-копирование).

# Виртуальные машины

Виртуальные машины (ВМ) — основной вычислительный ресурс платформы. В этом руководстве описывается создание, подключение и управление ВМ.

---

## Создание виртуальной машины

1. Перейдите в **Вычисления** → **Виртуальные машины**.
2. Нажмите **Создать**.
3. Выберите **Пул ресурсов** и **Образ** для ВМ.
4. Настройте **Вычисления** (ЦПУ и память), **Хранилище** (размер и тип диска) и **Сеть** (VPC/подсеть или классическая сеть), затем нажмите **Далее**.
5. Заполните параметры ВМ:

| Поле | Описание |
|---|---|
| **Имя** | Отображаемое имя ВМ |
| **Описание** | Необязательное описание |
| **Группа** | Организационная группа (необязательно) |
| **Пароль администратора** | Пароль для учётной записи администратора ОС |
| **Имя хоста** | Имя хоста в ОС (необязательно) |
| **Дата истечения** | Укажите срок действия или оставьте **Без ограничений** |

6. Проверьте итоговую конфигурацию и нажмите **ОК** для создания ВМ.

После создания нажмите **Консоль** для подключения к ВМ или **Ещё** для дополнительных действий.

---

## Действия с ВМ

После создания ВМ нажмите **Ещё** в списке виртуальных машин для доступа к следующим действиям:

| Действие | Описание |
|---|---|
| **Консоль** | Открыть браузерную VNC-консоль |
| **Выключить** | Выполнить корректное завершение работы гостевой ОС |
| **Приостановить** | Приостановить ВМ (сохраняет состояние в памяти) |
| **Перезагрузить** | Перезагрузить гостевую ОС |
| **Принудительно выключить** | Немедленно остановить ВМ |
| **Привязать ключевую пару** | Прикрепить SSH-ключевую пару для входа |
| **Управление снэпшотами/резервными копиями** | Управление снэпшотами и политиками резервного копирования |
| **Клонировать** | Клонировать ВМ |
| **Создать образ** | Создать встроенный образ из этой ВМ |
| **Экспортировать** | Экспортировать ВМ в формате OVA, VMA, OVF, MF или VMDK |
| **Удалить** | Удалить ВМ (перемещается в корзину) |

## Подключение к ВМ

### Консоль (браузер)

Нажмите **Консоль** в списке ВМ или на странице сводки ВМ. Откроется браузерная VNC-сессия без необходимости сетевого подключения к ВМ.

> Используйте консоль для доступа к ВМ во время установки ОС или когда ВМ недоступна по сети.

### SSH (Linux)

Убедитесь, что ВМ имеет доступный IP-адрес, затем:

```bash
ssh <имя_пользователя>@<ip-адрес-вм>
```

### RDP (Windows)

1. Откройте **Подключение к удалённому рабочему столу** на локальном компьютере.
2. Введите IP-адрес ВМ.
3. Войдите с учётными данными администратора, указанными при создании ВМ.

## Просмотр сведений о ВМ

Нажмите на имя ВМ, чтобы открыть страницу **Сводка**. Левая панель содержит:

| Вкладка | Что здесь |
|---|---|
| **Сводка** | Индикаторы использования ЦПУ, памяти, диска и графики производительности |
| **Снэпшоты** | Создание и управление снэпшотами |
| **Резервные копии и DR** | История резервных копий, политики и аварийное восстановление |
| **Задачи** | Статус текущих задач |
| **Оповещения** | События оповещений, относящиеся к этой ВМ |

Вкладка **Сводка** отображает детали конфигурации: гостевая ОС, расположение, хранилище, политика хранилища, имя хоста, теги, частота ЦПУ, использованное логическое пространство, используемая память и время работы.

## Снэпшоты

Снэпшоты фиксируют состояние диска ВМ в определённый момент времени.

### Создание снэпшота

1. Нажмите на имя ВМ → **Снэпшоты** → **Создать снэпшот**.
2. Опционально включите **Заморозить файловую систему гостя** для снэпшотов, согласованных с приложением (требуется установка VM Tools в гостевой ОС).
3. Нажмите **ОК**.

Новые ВМ по умолчанию используют **снэпшоты на основе внешних дисков**, которые освобождают место при удалении без влияния на производительность ВМ.

### Восстановление из снэпшота

1. В разделе **Снэпшоты** нажмите **Восстановить** рядом со снэпшотом.
2. Выберите **Все** диски или **Указанные** диски.
3. Опционально установите флажок **Включить ВМ после восстановления** и **Создать снэпшот перед восстановлением**.
4. Нажмите **ОК**.

> Восстановление из снэпшота откатывает диск ВМ к зафиксированному состоянию. Все данные, записанные после создания снэпшота, будут утрачены. Используйте **Создать снэпшот перед восстановлением**, чтобы сохранить текущее состояние.

## Резервное копирование

### Ручное резервное копирование

1. Нажмите на имя ВМ → **Резервные копии и DR**.
2. Нажмите **Резервная копия** для немедленного резервного копирования ВМ.

Прогресс отслеживается в разделе **Задачи**.

### Политика резервного копирования по расписанию

1. Нажмите на имя ВМ → **Резервные копии и DR** → **Настройка**.
2. Нажмите **Создать политику резервного копирования**.
3. Выберите ВМ для включения, настройте **Расписание** (еженедельно/ежедневно/ежечасно), **Метод хранения точек восстановления** и **Имя политики**.
4. Нажмите **ОК**.

### Восстановление файлов

Если файл был случайно удалён, можно восстановить отдельные файлы из резервной копии:

1. Нажмите на имя ВМ → **Резервные копии и DR** → **Просмотр файлов**.
2. Найдите файл в резервной копии, выберите его и нажмите **Скачать файл**.

> Восстановление файлов поддерживает Windows NTFS/FAT32 и Linux ext3/ext4/xfs. Файлы размером более 5 ГБ не поддерживаются для просмотра.

## Экспорт ВМ

Перед экспортом ВМ должна быть выключена.

1. В списке ВМ нажмите **Ещё** → **Экспортировать**.
2. Выберите формат файла: **OVA**, **VMA**, **OVF**, **MF** или **VMDK**.
3. Для OVA выберите целевую версию VMware Workstation.
4. Нажмите **Экспортировать** и дождитесь ссылки для скачивания.

---

## Клонирование ВМ

1. В списке ВМ нажмите **Ещё** → **Клонировать**.
2. Настройте имя и параметры клонированной ВМ.
3. Нажмите **ОК**.

---

## Удаление ВМ

1. В списке ВМ нажмите **Ещё** → **Удалить**.
2. Подтвердите удаление.

Удалённые ВМ перемещаются в **Корзину** (в разделе **Управление**) и могут быть восстановлены в течение 30 дней.

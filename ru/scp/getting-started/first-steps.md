# Первые шаги — SCP

После первого входа выполните следующие шаги, чтобы начать работу на платформе.

---

## Шаг 1 — Подайте заявку на первую виртуальную машину

Перейдите в **Compute → Virtual Machines** через мегаменю, затем нажмите **+ Request**.

<!-- скриншот: страница Virtual Machines — кнопка + Request -->

Откроется форма **Apply for VM**. Заполните все разделы сверху вниз, затем нажмите **OK** внизу страницы.

<!-- скриншот: форма Apply for VM — вся страница -->

### Resource Pool

Выберите пул ресурсов, в котором будет создана VM.

<!-- скриншот: Apply for VM — раздел Resource Pool -->

В данном развёртывании доступен пул **HCI**. Нажмите на него, чтобы выбрать.

### Image

Выберите образ операционной системы для VM. Используйте фильтры **All OSes** и **All Types** или строку поиска для сужения списка.

<!-- скриншот: Apply for VM — раздел Image -->

Доступные образы в данном развёртывании:

| Образ | ОС | Тип |
|---|---|---|
| openEuler-24.03-LTS-SP3 | openEuler | ISO |
| ubuntu-26.04 | Ubuntu | ISO |
| ubuntu-24.04.4 | Ubuntu | ISO |

> **Важно — ISO-образы требуют ручной установки ОС.** Все образы имеют тип ISO: VM загрузится с установочного диска. После создания VM необходимо подключиться через VNC-консоль и вручную завершить установку ОС, прежде чем VM будет готова к использованию. Подробнее — в [Шаге 2](#шаг-2--подключитесь-к-vm-и-установите-ос).

> **Нужного образа нет в списке?** Обратитесь к администратору с запросом добавить его в библиотеку образов.

### VM Count

В поле **Number of VMs** укажите количество VM для данной заявки. При первом запуске введите **1**.

<!-- скриншот: Apply for VM — раздел VM Count -->

### Compute

Задайте CPU и оперативную память для VM.

<!-- скриншот: Apply for VM — раздел Compute -->

**CPU:** нажмите на кнопку с нужным значением — **1 core**, **2 cores**, **4 cores**, **6 cores**, **8 cores**, **12 cores**, **16 cores** — или введите значение вручную в поле справа.

**Memory Size:** нажмите на кнопку с нужным значением — **1 GB**, **2 GB**, **4 GB**, **6 GB**, **8 GB**, **12 GB**, **16 GB**, **32 GB**, **48 GB**, **64 GB** — или введите значение вручную.

Нажмите **Show More**, чтобы раскрыть дополнительные параметры.

### Storage

Настройте хранилище для VM.

<!-- скриншот: Apply for VM — раздел Storage -->

| Поле | Описание |
|---|---|
| **Storage Tag** | Тип хранилища. В данном развёртывании доступен **High Performance Storage**. |
| **Storage Policy** | Выберите **Default Policy** или **HA Policy** (высокая доступность — данные копируются на несколько узлов). |
| **Disk** | Нажмите **+ Add**, чтобы добавить диск данных. Можно добавить до 3 дисков на VM. |

> **Обратите внимание о дополнительных дисках:** после создания VM добавленные диски появятся внутри ОС как неформатированные блочные устройства. Перед использованием их необходимо **разметить и смонтировать** из консоли VM.

### Networking

Выберите тип сети для VM.

<!-- скриншот: Apply for VM — раздел Networking -->

В данном развёртывании доступен тип сети **Classic Network**. Нажмите на него, чтобы выбрать.

> **Обратите внимание:** назначить статический IP или выбрать конкретную подсеть в этой форме нельзя. Адрес назначается инфраструктурой автоматически. Если вам нужна особая сетевая конфигурация — обратитесь к администратору.

### Отправка заявки

Когда все разделы заполнены, нажмите **OK** внизу формы (или **Cancel** для отмены).

<!-- скриншот: Apply for VM — кнопки OK и Cancel -->

После отправки заявка попадает в **очередь на согласование**. Чтобы проверить её статус, нажмите кнопку **Work Orders** в правом верхнем углу страницы Virtual Machines. После одобрения администратором VM будет подготовлена и появится в списке.

## Шаг 2 — Подключитесь к VM и установите ОС

Все доступные образы имеют тип ISO, поэтому при первом запуске VM загрузится в установщик ОС. Установку необходимо завершить через VNC-консоль, прежде чем VM станет доступна по SSH или RDP.

### Откройте VNC-консоль

1. В списке **Virtual Machines** найдите нужную VM.
2. В столбце **Operation** нажмите кнопку **Console**.
3. В новой вкладке браузера откроется VNC-сессия.

<!-- скриншот: VNC-консоль SCP — экран установщика ОС -->

Панель инструментов консоли содержит кнопки: **Power On**, **Suspend**, **Shut Down**, **Power Off**, **Restart**, **Reset**, **Hot Keys**, **Reset Password**, **Paste Command**, **Full Screen** и кнопку обновления.

> **Обратите внимание:** в верхней части консоли может отображаться жёлтый баннер — «vmTools is not installed on this virtual machine». Это ожидаемо для новой VM и устраняется после установки ОС. Подробности — в разделе vmTools в [FAQ](./faq.md).

4. Следуйте инструкциям установщика. Во время установки задайте пароль root или администратора — он понадобится для входа в VM.

> **Совет:** не закрывайте VNC-консоль до завершения установки. Продолжительность установки зависит от ОС.

### После установки — подключение по SSH (Linux)

После завершения установки и перезагрузки VM:

1. В списке VM найдите значение в столбце **IP**. Если отображается «-» — установите vmTools: в VNC-консоли нажмите **Install Now** в жёлтом баннере. После запуска vmTools IP появится в списке.
2. Подключитесь из терминала: `ssh <имя-пользователя>@<IP-VM>`
3. Используйте учётные данные, заданные во время установки ОС.

> **Не удаётся подключиться по IP?** VM находится в частной внутренней сети. Внешний доступ требует дополнительной настройки маршрутизации со стороны администратора. Обратитесь к администратору, если IP VM недоступен с вашего рабочего места.

### После установки — подключение по RDP (Windows)

1. В списке VM найдите значение в столбце **IP**.
2. Откройте **Подключение к удалённому рабочему столу** и введите IP-адрес VM.
3. Войдите с учётными данными, заданными во время установки ОС.

## Шаг 3 — Следите за метриками и задачами

Для просмотра детальных метрик работающей VM нажмите на её **имя** в списке Virtual Machines — откроется страница **VM Summary**.

<!-- скриншот: страница VM Summary -->

Страница Summary содержит:
- **Индикаторы Status** — текущая загрузка CPU, использование памяти (занято / свободно) и дискового пространства (занято / свободно)
- **Графики Running Status** — временны́е ряды по CPU, памяти, сетевому трафику (входящий/исходящий) и дисковому вводу-выводу. Период отображения настраивается, данные можно экспортировать.

В левой боковой панели страницы VM также доступны:
- **Snapshots** — создание снимков VM и управление ими
- **Tasks** — история операций для этой конкретной VM
- **Alerts** — оповещения, сработавшие для этой VM

Для просмотра платформенных оповещений перейдите в **Monitor Center → Alerts** в мегаменю.

**System → Tasks** в мегаменю показывает статус всех фоновых операций в вашем арендаторе — удобно отслеживать ход создания VM и других задач подготовки.

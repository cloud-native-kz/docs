# Глоссарий — SCP

| Термин | Определение |
|---|---|
| **SCP** | Self-Service Cloud Portal — веб-портал (доступен по адресу `https://<адрес-SCP>/login`), в котором арендаторы управляют виртуальными ресурсами на платформе HCI. |
| **Арендатор (Tenant)** | Изолированная организационная единица на платформе HCI с собственными VM и хранилищем. Каждый арендатор соответствует одному клиенту или команде. |
| **Apply for VM** | Название формы создания VM в SCP. Открывается кнопкой **+ Request** на странице Virtual Machines. |
| **Work Orders** | Очередь заявок на создание VM, ожидающих одобрения администратора. Доступна через кнопку Work Orders в правом верхнем углу страницы Virtual Machines. |
| **Виртуальная машина (VM)** | Программный компьютер, работающий на инфраструктуре HCI. Каждой VM выделяются vCPU, RAM и дисковое пространство. |
| **vCPU / Core** | Виртуальное ядро процессора, назначенное VM. В форме Apply for VM обозначается как «cores». |
| **Resource Pool** | Логическая группа физических вычислительных ресурсов и ресурсов хранилища на платформе HCI. Выбирается при подаче заявки на VM. В данном развёртывании пул называется **HCI**. |
| **ISO-образ** | Образ установочного диска ОС (например, Ubuntu, openEuler). VM, созданные из ISO-образов, загружаются в мастер установки ОС — установку необходимо завершить через VNC-консоль перед использованием VM. |
| **Системный диск (System Disk)** | Загрузочный диск VM. Содержит операционную систему после установки. |
| **Диск данных (Data Disk)** | Дополнительный том хранилища, добавляемый к VM. Можно добавить до 3 дисков при создании VM. Перед использованием необходимо разметить и смонтировать внутри ОС. |
| **Storage Tag** | Метка, определяющая тип (уровень) хранилища для диска. В данном развёртывании доступен **High Performance Storage**. |
| **Storage Policy** | Политика избыточности данных для диска. **Default Policy** — одна копия данных; **HA Policy** — данные копируются на несколько узлов для высокой доступности. |
| **Classic Network** | Доступный тип сети для арендаторов в данном развёртывании. Подключает VM к внутренней сети инфраструктуры. |
| **Elastic IP** | Публичный IP-адрес, который администратор может назначить VM для внешнего доступа. Отображается в столбце Elastic IP в списке Virtual Machines, но арендатор не может назначить его самостоятельно. |
| **VNC-консоль** | Браузерный дисплей для прямого доступа к VM из портала. Открывается кнопкой **Console** в столбце Operation. Используется для установки ОС и для экстренного доступа при недоступности SSH/RDP. |
| **vmTools** | Гостевой агент, устанавливаемый внутри VM после установки ОС. Необходим для отображения IP-адреса VM в портале, работы функций Reset Password, Bind Key Pair и автоматического восстановления при сбое. В VNC-консоли отображается ссылка Install Now, если vmTools не установлен. |
| **VM Summary** | Страница с детальной информацией о VM, открываемая нажатием на имя VM в списке. Содержит текущие показатели CPU, памяти и диска, а также временны́е графики CPU, памяти, сети и дискового ввода-вывода. |
| **Change configuration** | Действие для конкретной VM (в меню More), позволяющее изменить количество vCPU и объём RAM. |
| **Снимок (Snapshot)** | Сохранённое состояние VM на определённый момент времени (диск и память). Позволяет откатить VM к этому состоянию — например, после неудачного обновления или для отладки. Не является резервной копией — хранится на той же инфраструктуре. Создаётся через More → **Take Snapshot**. Управление через More → **Snapshots** или боковую панель страницы VM. |
| **Validity Period** | Срок действия VM, задаётся в форме Apply for VM. По умолчанию — **Unlimited** (бессрочно). Значение **Specified** выбирается только для временных VM с автоматическим завершением. После истечения срока VM может быть автоматически остановлена или освобождена. Продление — через администратора. |
| **Tasks** | Доступны в разделе **System → Tasks**. Журнал фоновых операций (создание, удаление, изменение питания VM) и их статус. |
| **Key Pairs** | SSH-ключи, управляемые в разделе **System → Key Pairs**. Используйте **+ Create Key Pair** для автогенерации ключевой пары (скачайте приватный ключ сразу — он показывается только один раз) или для импорта существующего публичного ключа (Base64). После создания привяжите ключ к работающей Linux VM через More → **Bind Key Pair** (требуется vmTools). |
| **Monitor Center** | Раздел мониторинга в мегаменю SCP. Содержит **Alerts** — оповещения о состоянии и работоспособности ресурсов. |
| **HCI** | Hyper-Converged Infrastructure — базовая платформа, объединяющая вычислительные ресурсы, хранилище и сеть в единой системе. SCP работает поверх HCI. |

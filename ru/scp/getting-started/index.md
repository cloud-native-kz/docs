# Начало работы с SCP

Self-Service Cloud Portal (SCP) — это ваше рабочее пространство арендатора на платформе HCI. Портал позволяет запрашивать виртуальные машины и управлять ими, а также просматривать оповещения.

Этот документ проведёт вас через получение доступа, вход в систему и знакомство с порталом.

## 1. Как устроен доступ

Доступ к SCP **предоставляется администратором**. Самостоятельной регистрации нет.

Прежде чем вы сможете войти в портал, администратор должен:

1. Создать для вас **учётную запись арендатора** на платформе HCI.
2. Установить начальный пароль (или предоставить временный).
3. Определить ресурсы, доступные вашему арендатору, на уровне платформы.

Заявки на VM, которые вы подаёте через портал, проходят через одобрение администратора — только после этого VM создаётся.

URL портала и учётные данные для входа вы получите от администратора или менеджера аккаунта.

> **Не получили данные для входа?** Обратитесь к менеджеру аккаунта или напишите на [cns-support@fcd.kz](mailto:cns-support@fcd.kz).

## 2. Вход в систему

Откройте URL портала, предоставленный администратором, в браузере. Страница входа находится по адресу:

```
https://<адрес-SCP>/login
```

<!-- скриншот: страница входа в SCP -->

**Порядок действий:**

1. Введите ваш **логин или email** в поле Username/Email.
2. Введите ваш **пароль**.
3. Нажмите **Login**.

После успешного входа вы попадёте на страницу **Virtual Machines**.

> **Обратите внимание:** используйте современный браузер — Chrome, Firefox или Edge. Internet Explorer не поддерживается.

---

## 3. Сброс пароля

**Если вы забыли пароль:** на странице входа нажмите ссылку **Forgot Password?** справа от поля Password и следуйте инструкциям на экране.

<!-- скриншот: страница входа — ссылка Forgot Password? -->

**Чтобы сменить пароль после входа:** нажмите на имя пользователя в правом верхнем углу (отображается как **Имя / Роль**, например *Zhanat / Member*), откроется выпадающее меню — выберите **Change Password**.

<!-- скриншот: выпадающее меню аккаунта -->

---

## 4. Первый вход в портал

После входа вы попадёте на страницу **Virtual Machines** — основную рабочую область портала.

<!-- скриншот: страница Virtual Machines при первом входе, нет VM -->

Отсюда вы можете подать заявку на первую VM с помощью кнопки **+ Request** или перейти в другие разделы через меню-гамбургер (☰) в левом верхнем углу.

> **Готовы создать первую VM?** Смотрите раздел [Первые шаги](./first-steps.md).

# Обзор портала — SCP

Этот раздел описывает структуру и основные области Self-Service Cloud Portal.

---

## Навигация

SCP использует **верхнюю панель навигации**. Чтобы перейти между разделами, нажмите **меню-гамбургер (☰)** в левом верхнем углу. Откроется мегаменю с поисковой строкой и следующими разделами:

<!-- скриншот: мегаменю SCP в открытом состоянии -->

**Compute**
- Virtual Machines
- Physical Machines

**Hybrid Cloud**
- Third-Party Public Cloud

**IDaaS**
- Service Provider Management

**Monitor Center**
- Alerts

**System**
- Tasks
- Key Pairs

В левой части мегаменю отображается панель **Resources / My Favorites** для быстрого доступа к закреплённым страницам.

В **правом верхнем углу** отображается ваш аккаунт в формате **Имя / Роль** (например, *Zhanat / Member*). В верхней панели также находятся переключатель языка, иконки уведомлений и кнопка **Work Orders** для отслеживания заявок на создание VM.

<!-- скриншот: верхняя панель SCP — аккаунт и переключатель языка -->

---

## Стартовая страница

После входа вы попадаете на страницу **Virtual Machines**. Отдельного дашборда или сводки по ресурсам нет. Чтобы посмотреть потребление ресурсов конкретной VM, нажмите на её имя — откроется страница **VM Summary**.

---

## Virtual Machines

**Compute → Virtual Machines** — основная рабочая область портала. Здесь отображается список всех VM вашего арендатора.

<!-- скриншот: список Virtual Machines — пустое состояние -->

В таблице отображаются следующие столбцы:

| Столбец | Описание |
|---|---|
| **Name** | Отображаемое имя VM |
| **Status** | Текущее состояние. Возможные значения: Running, Stopped, Error, Alerting и другие. |
| **Resource Pools** | Пул ресурсов, в котором находится VM |
| **Guest OS** | Операционная система, установленная на VM |
| **IP** | Внутренний IP-адрес VM. Отображается **-**, если vmTools не установлен на VM. |
| **Elastic IP** | Публичный IP-адрес, назначенный VM администратором (если есть) |
| **CPU** | Количество назначенных виртуальных ядер |
| **Memory** | Объём назначенной RAM |
| **Memory Usage** | Текущее потребление памяти |
| **Storage** | Общий объём дискового пространства |
| **Storage Usage** | Текущее использование диска |
| **Operation** | Кнопки действий для конкретной VM: **Console** и **More** |

**Действия панели** (применяются к выбранным VM):

| Кнопка | Описание |
|---|---|
| **+ Request** | Открыть форму Apply for VM для подачи заявки на новую VM |
| **Power On** | Запустить выбранные VM |
| **Shut Down** | Корректно завершить работу выбранных VM |
| **Columns** | Показать или скрыть столбцы таблицы |
| **More** | Дополнительные действия над группой VM |

**Действия для конкретной VM** — нажмите **Console** для открытия VNC-консоли или **More** для выпадающего меню:

| Действие | Описание |
|---|---|
| **Power On** | Запустить VM |
| **Shut Down** | Корректно завершить работу VM |
| **Suspend** | Приостановить VM с сохранением состояния в памяти |
| **Reset Password** | Сбросить пароль пользователя ОС (требуется vmTools) |
| **Bind Key Pair** | Привязать SSH-ключ к VM (требуется vmTools) |
| **Reboot** | Корректно перезапустить VM |
| **Reset** | Принудительно перезапустить VM без завершения ОС |
| **Power Off** | Принудительно выключить VM немедленно |
| **Edit** | Переименовать VM или изменить описание |
| **Change configuration** | Изменить количество vCPU и объём RAM у VM |
| **Take Snapshot** | Создать снимок текущего состояния VM |
| **Snapshots** | Просмотреть снимки VM и управлять ими |

### Страница VM Summary

Нажмите на **имя VM** в списке, чтобы открыть страницу **VM Summary**. Страница содержит:

<!-- скриншот: страница VM Summary -->

**Раздел Status** — три индикатора с текущими показателями:
- **Total CPU** — процент загрузки CPU и тактовая частота
- **Total Memory** — использованная и оставшаяся RAM
- **Total Disk Space** — использованное и оставшееся дисковое пространство

**Раздел Running Status** — графики за выбранный период с возможностью экспорта:
- **CPU** — загрузка CPU во времени
- **Memory** — использование памяти во времени
- **Network** — входящий/исходящий трафик (bps и pps)
- **Disk** — скорость ввода-вывода и IOPS

**Панель Configuration** (справа) — все параметры VM: имя, статус, ОС, пул ресурсов, тип сети, политика хранилища, время работы, порядок загрузки и статус vmTools. При прокрутке панели вниз также отображаются подключённые диски (имя, размер, тег хранилища, файл диска) и сетевые интерфейсы (NIC1, NIC2 и т. д.).

**Левая боковая панель** — подразделы выбранной VM:
- **Summary** — страница метрик, описанная выше
- **Snapshots** — управление снимками VM
- **Tasks** — история операций для этой VM
- **Alerts** — оповещения, сработавшие для этой VM

## Physical Machines

**Compute → Physical Machines** — список физических серверов, выделенных вашему арендатору. В данном развёртывании физические серверы арендаторам не выделяются, поэтому страница отображает «No data available».

---

## Hybrid Cloud

**Hybrid Cloud → Third-Party Public Cloud** — подключения к внешним публичным облачным провайдерам, настроенные администратором.

## IDaaS

**IDaaS → Service Provider Management** (в портале отображается как **Service Providers**) позволяет настроить SSO (Single Sign-On) для пользователей. После добавления провайдера локальные пользователи смогут авторизоваться через SSO, что упрощает управление учётными записями.

Если провайдеры ещё не созданы, страница отображает «No service provider available now.» Обратитесь к администратору для настройки.

---

## Monitor Center

**Monitor Center → Alerts** — оповещения о состоянии и работоспособности ваших ресурсов.

<!-- скриншот: Monitor Center — страница Alerts -->

Метрики конкретной VM (CPU, память, сеть, диск) доступны прямо на странице **VM Summary** — нажмите на имя VM в списке Virtual Machines, чтобы её открыть.

## System

| Пункт | Описание |
|---|---|
| **Tasks** | Журнал фоновых операций (создание, удаление VM, изменение питания) и их статус |
| **Key Pairs** | SSH-ключи для аутентификации на Linux VM без пароля. Используйте **+ Create Key Pair** для автоматической генерации ключевой пары (скачайте приватный ключ сразу — он показывается только один раз) или для импорта существующего публичного ключа. После создания привяжите ключ к работающей VM через More → **Bind Key Pair** (требуется vmTools). |
